# 🚀 E7T MARKETPLACE

### Plataforma web de comercio digital

E7T MARKETPLACE es un proyecto de desarrollo web que busca conectar compradores y vendedores de productos y servicios digitales mediante una plataforma organizada y segura.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Supabase
- SQL
- Cloudflare Pages

## 💻 Funcionalidades desarrolladas

- Registro e inicio de sesión de usuarios.
- Perfiles de compradores y vendedores.
- Catálogo de categorías y productos digitales.
- Publicación y administración de ofertas.
- Chat entre compradores y vendedores.
- Panel de administración.
- Diseño adaptable a computadoras y celulares.
- Interfaz en español e inglés.

## 🌐 Demostración

**Visitar E7T MARKETPLACE:** https://e7t-5rd.pages.dev/

## 📌 Estado del proyecto

Proyecto personal en desarrollo continuo. Algunas funcionalidades se encuentran en fase de pruebas.

## 🎯 Objetivo

Desarrollar una plataforma de comercio digital aplicando conocimientos de frontend, bases de datos, autenticación, administración de usuarios y despliegue web.
